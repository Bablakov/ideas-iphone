# Идеи (ideas-iphone)

Быстрая запись идей голосом, текстом и видео для iPhone и Android. PWA: ставится через
Safari → «На экран „Домой“», работает без сети, ничего не требует кроме хостинга (GitHub Pages).

Сайт: https://bablakov.github.io/ideas-iphone/

## Что умеет сейчас (шаг 1 — только телефон)

- **Запись**: большая кнопка голоса (запись сохраняется сразу при остановке), видео (снять или выбрать
  из галереи), текстовая заметка, необязательная ссылка на видео. Набранный текст — это черновик,
  он не пропадёт, если приложение закроют.
- **История**: записи по дням, фильтры «Все / Необработанные / Обработанные», выбор конкретного дня.
- **Карточка записи**: плеер, правка текста и ссылки, пометка «обработана», удаление (с подтверждением).
- Всё хранится на устройстве в IndexedDB (метаданные — стор `ideas`, файлы — стор `media`).

## Что дальше

2. **Синхронизация с ПК** через GitHub: текст и метаданные — приватный репозиторий `ideas-data`
   (`inbox/<id>/item.json`), аудио и видео — кусками до 10 МБ (`parts` в манифесте, склейка простой
   конкатенацией байт, проверка sha256). Поля `synced` в записях уже заложены.
3. **Воркер на ПК**: `git pull`, Whisper, конспект, картинка, выгрузка во флешкарды / Telegram.

## Разработка

```bash
npm install
npm run dev      # локально (микрофон требует HTTPS или localhost)
npm test         # тесты
npm run build    # проверка типов + сборка
npm run icons    # перерисовать иконки
```

Каждый push в `main` собирает и выкладывает сайт через GitHub Actions (`.github/workflows/pages.yml`).

## Ограничения iOS

- Запись звука — только по нажатию и только по HTTPS; формат m4a (AAC).
- Фоновой синхронизации у Safari нет — отправка накопленного будет происходить при открытии приложения.
- Share-sheet из других приложений для PWA на iOS недоступен (на Android есть).
