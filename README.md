# Идеи (ideas-iphone)

Быстрая запись идей голосом, текстом и видео для iPhone и Android. PWA: ставится через
Safari → «На экран „Домой“», работает без сети, ничего не требует кроме хостинга (GitHub Pages).

Сайт: https://bablakov.github.io/ideas-iphone/

## Что умеет сейчас

- **Новая карточка**: в одну карточку можно положить аудио, видео (снять или выбрать), текст и ссылку на
  видео (появляется по галочке). Карточка создаётся кнопкой «Сохранить карточку». Пока она не сохранена,
  всё лежит в черновике в IndexedDB и переживает закрытие приложения.
- **Статусы**: необработанная → обработанная; **архив** (отдельная вкладка) убирает карточку с глаз, но не
  удаляет — её можно вернуть. «Удалить навсегда» стирает карточку вместе с файлами.
- **История**: карточки по дням, фильтры «Все» (без архива) / «Необработанные» / «Обработанные»,
  диапазон дат «с — по» (по умолчанию сегодня; «Все дни» снимает ограничение).
- **Настройки**: репозиторий, ветка и токен GitHub, проверка доступа, ручная синхронизация, состояние.
- Всё хранится на устройстве в IndexedDB: `ideas` (метаданные), `media` (файлы под ключами
  `<id>:audio` / `<id>:video`), `draft` (черновик).

## Синхронизация через GitHub

Приложение само обменивается карточками с приватным репозиторием данных (по умолчанию
`Bablakov/ideas-data`) через GitHub API — git на телефоне не нужен. Запускается при открытии, при
появлении сети и через пару секунд после любой правки. Фоновой синхронизации у iOS-PWA нет.

Формат в репозитории (его же читает и дополняет воркер на ПК):

```
inbox/<id>/item.json     метаданные, текст, статус, updated, описание частей файлов
inbox/<id>/audio.000     файл кусками по 10 МБ: audio.000, audio.001, …
inbox/<id>/video.000     (склейка — простая конкатенация байт, целостность — sha256 из item.json)
```

- Побеждает версия с более поздним `updated` (одна карточка — один файл, конфликтов по строкам нет).
- Удаление оставляет в репозитории «надгробие» (`item.json` с `deleted: true`, без файлов), чтобы
  другое устройство не вернуло карточку обратно.
- Каждая карточка уходит отдельным коммитом (Git Data API), отправка и скачивание повторяемы.

## Что дальше

- **Воркер на ПК**: `git pull`, Whisper, конспект, картинка, выгрузка во флешкарды / Telegram;
  результат дописывается в `item.json`, статус меняется на `processed`.

## Разработка

```bash
npm install
npm run dev      # локально (микрофон требует HTTPS или localhost)
npm test         # тесты
npm run build    # проверка типов + сборка
npm run icons    # перерисовать иконки
```

Каждый push в `main` собирает и выкладывает сайт через GitHub Actions (`.github/workflows/pages.yml`).

## Ограничения iOS

- Запись звука — только по нажатию и только по HTTPS; формат m4a (AAC).
- Фоновой синхронизации у Safari нет — отправка накопленного будет происходить при открытии приложения.
- Share-sheet из других приложений для PWA на iOS недоступен (на Android есть).
